말풍선

필드 포켓몬 머리 위에 뜨는 말풍선이 어느 상황에 나오는지 모아 뒀어요. 같은 말풍선이 여러 상황에 나올 수 있어요.

버전 읽는 법

작업실 = 이 작업실 화면 버전이에요. 게임 = 게임 코드 버전(프로필 오른쪽 아래 숫자)이고, 데이터 = 작업실에서 배포하기를 누른 횟수예요. 작업실이나 게임이 새로 올라가면 다시 열 때 바뀌어요.
포켓몬을 고르면 등급마다 나올 확률이 나와요.
포켓몬을 누르면 티어를 옮길 수 있어요.
