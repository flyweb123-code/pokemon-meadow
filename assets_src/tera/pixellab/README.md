# Tera crystal pixel art (PixelLab Pro)

Made in the PixelLab web app (Pro model, "Remove background" on). Every file has a transparent background.

- `crown_<type>.png` (19 types) + `crown_<type>_b.png` (2nd candidate): 64px wide, content trimmed, at least 48px tall (some up to 62px).
- `shard_1~6.png`: colourless crystal shards, trimmed (about 26-43 x 57-61 px). Tint by type in code.
- `cluster_1~2.png` (+ `_b`): 128x128 colourless crystal clusters to cover a Pokémon.
- `sheets/`: the raw 4x4 (64px) / 2x2 (128px) candidate sheets each run returned, for re-picking.
- `preview.png`: contact sheet of the picks (2x, dark background).
