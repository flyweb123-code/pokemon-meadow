# 가짜 위치로 장소 찾기 시험하기

알을 주운 곳이 "서울 석촌동"처럼 동까지만 나올 때, 걷지 않고 원인을 보는 방법이에요.

1. Mac 에서 아이폰을 연결하고 Xcode 로 PokeGrow 를 실행해요 (▶).
2. 실행 중에 Xcode 아래 디버그 막대의 위치 화살표 버튼(Simulate Location) › **Add GPX File to Project…** 로
   이 폴더의 `SeokchonLake.gpx` 나 `OlympicPark.gpx` 를 고르면 폰 위치가 그 길을 따라 움직여요.
   (다시 쓸 땐 같은 버튼 목록에 이름이 떠요. 그만하려면 "Don't Simulate Location".)
3. 게임 설정 › 운영자 › **장소 찾기 시험** 을 눌러요. 지금 위치로 장소를 찾은 단계별 결과가 나와요.
   - `동네:` 아이폰이 준 동네 이름
   - `400m: 장소 N곳 (한국어 이름 M)` 반경마다 애플 지도가 준 장소 수와 오류
   - `보낸 이름:` 게임으로 보낸 최종 이름
   아래에는 화면이 꺼진 동안 자동으로 찾은 최근 8번의 기록도 함께 나와요 (`앱 꺼짐(백그라운드)` 표시).

걸음 수는 실제로 걸어야 늘어서, 가짜 위치만으로는 알이 주워지지 않아요. 이 시험은 장소 이름 찾기만 봐요.
