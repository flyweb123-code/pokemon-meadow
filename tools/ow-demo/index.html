체육관 문 밖 모험 · 1단계 시연

실제 게임의 이벤트 필드 엔진(gym/ev.js)을 그대로 불러 돌려요. 체육관 문을 나서면 돌담시티, 동쪽으로 나가면 3번 도로예요.

하루치 마을 소식·의뢰·떠돌이 트레이너·풀숲 포켓몬을 AI가 정해진 틀 안에서 만들어요. 실제 게임에선 서버가 매일 새벽에 미리 만들어 둬요.

해 볼 것

  • 미리 생성게시판(체육관 왼쪽 표지판)에서 오늘 소식 읽기
  • 미리 생성마을 사람 대사·오늘의 의뢰 → 3번 도로에서 반짝이는 곳 찾기
  • 미리 생성3번 도로 떠돌이 트레이너, 풀숲 야생 포켓몬
  • 실시간 AI동쪽 출구 앞 이야기꾼 할머니에게 "직접 말 걸기"
  • 피카츄에게 말 걸기, 가방의 모험 수첩, 포켓몬 센터·마트·집 들어가기

조작: 왼쪽 스틱(키보드 방향키) · A(스페이스·Z) · 달리기(Shift). 시연이라 배틀 화면과 효과음은 뺐어요.
